# Third-party notices

KeyCourier's application source uses Apple system frameworks. Its development and optional delivery workflows also invoke tools that are distributed separately:

- XcodeGen, used to generate the Xcode project.
- `age`, used for owner-configured encrypted recovery and remote delivery.
- OpenSSH, used for owner-allowlisted remote transport.

Those tools are not redistributed by this repository. Their respective licences and notices apply to their installations. Before distributing a binary package that embeds any additional dependency, update this file and include that dependency's required licence text.
